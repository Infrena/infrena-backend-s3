# Code of Conduct

This project follows the same Code of Conduct as the rest of Infrena, which is
the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html)
version 2.1.

The full text is in the engine repository:
[infrena/infrena/CODE_OF_CONDUCT.md](https://github.com/infrena/infrena/blob/main/CODE_OF_CONDUCT.md)

Report unacceptable behaviour to **conduct@infrena.dev**. Reports are handled
privately.

For a security vulnerability, use [SECURITY.md](SECURITY.md) instead — that has
its own private reporting path.
